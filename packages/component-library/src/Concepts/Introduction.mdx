# Universal Budget Component Library

Welcome to the **Universal Budget Component Library**. Explore our UI components, see how they look across different themes, and learn how to use them in your code.

- ✨ **Browse components** in the sidebar
- 🎨 **Switch themes** using the toolbar above

Select a component from the sidebar to explore its documentation, variants, and interactive controls.
